# Jev Trading Lab

Evidence-first feasibility lab for two independent paper-trading experiments:

- liquid non-sports Polymarket markets;
- liquid S&P 100 multi-day stock swings.

OpenAI builds timestamped evidence. Jev makes bounded decisions. Deterministic code owns arithmetic, risk, costs, paper execution, and evaluation.

**No live execution exists in the initial release.**
